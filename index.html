Install it anywhere.

Hotaru runs on every platform. On Windows, Linux and Android it installs straight from the browser — no store, no download, no runtime. It gets a real window, its own icon, and keeps working offline.

iPhone & iPad

A native app, not a wrapped web page.

Open the web app in Edge or Chrome, then Install Hotaru from the address bar. It lands in the Start Menu like any other app.
